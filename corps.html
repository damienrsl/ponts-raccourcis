Ponts Raccourcis · 22 novembre 2026

Claude depuis la poche, sans prendre le bateau

Tokn a déjà une porte d'actions. Il lui manquait les rampes : le Bouton Action, Siri, la feuille de partage, les automatisations. Cette page est la carte complète, avec 7 ponts prêts à installer et le plan des deux vagues suivantes.

Le contre-argument, d'abord

Chaque pont est une entrée de plus

Le contradicteur du 2 novembre l'avait dit : pas de cinquième outil. Un catalogue de trente raccourcis, c'est trente endroits où oublier un geste.

Ma réponse. Un pont n'est pas un outil : tout arrive dans le même Tokn, dans le même fil. Mais la règle tient : trois ponts installés d'abord (Tokn, Lien, Photo). Les autres n'entrent que quand l'un des trois a servi cinq jours de suite.
Ce qui existe déjà

La porte est ouverte depuis le 21 novembre

Les widgets Scriptable parlent à une seule adresse du cerveau. L'app Raccourcis sait parler à la même adresse. Donc un pont = deux actions natives et zéro ligne de code serveur.

Brancher les rampes, en cinq minutes

  1. Bouton Action : Réglages → Bouton Action → Raccourci → Tokn. Un appui long, tu parles.
  2. Toucher le dos : Accessibilité → Toucher → Toucher le dos → deux fois = Photo à Claude, trois fois = Vocal long.
  3. Siri : rien à régler, le nom du raccourci est la phrase. « Dis Siri, Tokn », « Dis Siri, Dis-moi ». Marche dans les AirPods et sur l'Apple Watch si l'iPhone est à côté.
  4. Centre de contrôle : appui long → Ajouter un contrôle → Raccourci → Tokn. Accessible écran verrouillé.
  5. Écran verrouillé : le widget « Raccourci » d'Apple à la place d'un widget Scriptable. Sur iOS 27, le widget XL lance plusieurs raccourcis d'un coup.

La méthode, deux ans d'avance

L'iPhone trie, Claude exécute

Dans deux ans tout le monde dictera à une IA. L'avance, c'est que le message arrive déjà trié et déjà contextualisé, sans que tu aies tapé un mot de plus.

01

Le modèle local comme trieur

L'action « Utiliser un modèle » d'iOS 26 tourne sur l'iPhone, gratuite, hors ligne. Elle lit ta dictée et renvoie un petit dictionnaire : espace (Contenu, Marque, Business, Perso), urgence, titre. Le raccourci envoie ensuite à Tokn dans le bon espace. Zéro jeton Claude pour le routage.

02

Le contexte voyage avec le message

Raccourcis connaît l'heure, le lieu (domicile ou travail en iOS 27), le Focus actif, la batterie, la dernière app, le texte sélectionné. Le raccourci les colle en tête du message : « 23 h 10, hôtel, Focus Sommeil ». Claude répond court et au bon moment, sans que tu l'expliques.

03

Le stockage partagé des raccourcis

iOS 27 ajoute un stockage global entre raccourcis, synchronisé iCloud : le jeton Tokn y vit une fois, tous les ponts le lisent. Renouveler le jeton = changer une valeur.

04

Décrire un raccourci au lieu de le construire

iOS 27 crée un raccourci à partir d'une phrase. Avec cette page comme référence, tu peux dire « fais un raccourci qui envoie ma capture à Tokn » et l'iPhone le monte. Les ponts deviennent ta langue, pas ma fabrique.

05

Trois règles qui ne bougent pas

  • Un geste = une intention. Jamais de menu dans un raccourci.
  • Un pont ne paie, ne publie, n'envoie jamais. Il note et lance. Une question de Claude revient en notification, comme aujourd'hui.
  • Tout se défait : un raccourci se supprime, un jeton se renouvelle, un sujet se ferme.
Vague 3 · l'app native

Quand le compte Apple Developer est actif

Les App Intents transforment chaque geste en action système : plus d'adresse ni de jeton, l'iPhone connaît Tokn comme il connaît Messages. Ce qui est à construire dans le projet tokn-ios :

IntentCe que ça ouvre
Lancer un sujet (texte, espace)« Dis à Tokn de … », Spotlight Mac avec le texte sélectionné, Bouton Action contextuel
Dis-moi (question)Siri lit la réponse (dialog), encart interactif avec « Continuer »
Continuer (sujet)Les sujets deviennent des entités : Siri et Spotlight les trouvent par leur titre
Stop · Le point (mission)Contrôles du Centre de contrôle, bouton dans la Dynamic Island
Fini · Je bloque (tâche)Widget interactif à boutons, sans ouvrir l'app (fin de Scriptable)

Contraintes Apple relevées : la phrase Siri contient le nom de l'app et un seul paramètre ; l'intent tourne sans ouvrir l'app ; les entités ont un identifiant stable (le `sid` de Tokn convient). Chaque intent apparaît aussi dans Raccourcis : la vague 1 se remplace par des actions natives, sans rien réapprendre.

Les limites, franchement

Ce qui peut casser

Tailscale

Tous les ponts passent par le cerveau en Tailscale. Un seul VPN à la fois sur iOS : Astrill coupe Tailscale. En Chine, il faudra la porte trycloudflare comme pour Calories.

Le jeton dans les raccourcis

C'est le jeton de widget, le même que Scriptable, joignable seulement dans le tailnet. S'il fuit : Tokn → renouveler, et je refabrique les sept fichiers en une commande.

Apple Watch et CarPlay sans iPhone

La montre seule n'a pas le VPN. Siri au poignet marche quand l'iPhone est à portée, pas en courant sans lui.

Pas de réponse dans le raccourci

Raccourcis coupe une requête longue. Claude répond par notification et dans Tokn ; seul « Dis-moi lu » (vague 2) attend une réponse courte.

Rien vu sur le vrai iPhone

Le Mac signe, l'iPhone juge. Premier import = test. Si un fichier refuse de s'ouvrir, le nom me suffit pour corriger.
